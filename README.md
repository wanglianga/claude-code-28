# 艺芽美术 · 城市美术培训班作品点评与升班评估系统

## 原始需求

> 设计城市美术培训班作品点评与升班评估页面，可使用 Vue 3、TypeScript 和 Pinia。老师在每节课后上传学生作品照片，标记构图、线条、色彩、观察能力、创意表达、课堂专注和是否需要家庭练习。页面按学生、班级、课程主题和阶段目标展示作品成长轨迹。家长查看点评时，可以看到老师对本次作品的具体建议、下次课程准备和孩子课堂状态；若家长追问进步慢、作品不像样或是否适合升班，老师可以从历史作品和能力标签中选择证据回复。升班评估时，教学主管需要比较同龄段目标、出勤、作业完成、老师点评、家长配合和孩子意愿，再决定升班、留班、转兴趣班或建议一对一辅导。若学生换老师、请假补课、参加比赛或家长要求退费，页面要把作品、点评、沟通和课时消耗关联起来，避免只凭单次作品判断教学质量。页面还会把续费建议与教学证据拆开呈现，避免家长把销售沟通误解成升班判断。家长会前，页面还能生成每名学生的阶段说明。页面还要把教学目标和商业续费分开展示，主管既能看作品成长，也能看到家长沟通风险、课时消耗和升班建议是否一致。

## 技术栈

- 前端：Vue 3 + TypeScript + Pinia + Vue Router + Vite（手绘 SVG 雷达图/趋势图，无重型图表依赖）
- 后端：Node.js 20 + Express + TypeScript + PostgreSQL 16（`pg` 纯 JS 驱动）
- 部署：多阶段 Dockerfile（非 root 用户 + HEALTHCHECK）+ docker compose（app + db）

## 一键启动（验证方式 = 宿主 docker compose up）

```bash
# 可选：cp .env.example .env   # 环境已注入 CC_PUBLISH_PORT 时无需此步
docker compose up -d --build

# 查看应用实际映射端口（宿主端口由 CC_PUBLISH_PORT 决定）
docker compose port app 3000
# 浏览器访问 http://localhost:<端口>   （容器内验证可用 http://host.docker.internal:<端口>）

# 结束验证后释放资源
docker compose down
```

- 仅 `app` 服务发布端口到宿主（`${CC_PUBLISH_PORT}:3000`）；PostgreSQL 只在 compose 内部网络以服务名 `db` 访问。
- 首次启动自动建表并写入演示数据（3 个班级、6 名学生、12 周课程、逐课六维点评、出勤/作业/提问/事件/续费/评估）。
- 作品图片为启动时生成的 SVG 占位儿童画；老师上传的照片持久化在 `app_data` 卷。

## 功能地图（对应需求）

| 需求 | 实现位置 |
| --- | --- |
| 课后上传作品照片 + 标记构图/线条/色彩/观察/创意/专注 + 是否需家庭练习 | 老师端「我的班级 → 去点评」 |
| 按学生/班级/课程主题/阶段目标展示成长轨迹 | 「成长轨迹」页：学生/班级筛选 + 主题/阶段目标过滤 + 雷达图（对照同龄段目标）+ 趋势图 |
| 家长看具体建议、下次课准备、课堂状态 | 家长端「孩子的课堂 → 本次点评」 |
| 家长追问进步慢/不像样/是否升班，老师用历史作品+能力标签作证据回复 | 家长端「提问与老师回复」；老师端「家长提问 → 选择证据并回复」 |
| 升班评估：同龄段目标/出勤/作业/老师点评/家长配合/孩子意愿 → 升班/留班/转兴趣/一对一 | 主管端「学生详情 → 升班评估」（数据自动汇总，结论四选一） |
| 换老师/请假补课/比赛/退费 → 作品、点评、沟通、课时消耗关联 | 主管端「学生详情 → 事件时间线」 |
| 续费建议与教学证据拆开呈现 | 家长端独立「续费建议」页（带"商业沟通"标识与免责声明）；主管端总览分"教学证据区/商业与风险区" |
| 家长会前生成每名学生阶段说明 | 主管端「学生详情 → 阶段说明 → 生成」，家长端可查看、可打印 |
| 教学目标与商业续费分开展示、升班建议一致性 | 主管端「教学总览」：成长趋势/出勤/作业 vs 课时消耗/续费/沟通风险，自动一致性提示（如"退费处理中存在续费推销"） |

## 演示动线建议

1. `supervisor` 登录 → 教学总览：看黄思远（退费+高风险+续费不一致）、刘一诺（换老师波动）等提示。
2. 点进苏晴 → 升班评估：查看自动汇总的六维目标对照与历史评估（升班）。
3. 点进任意学生 → 阶段说明 → 生成「2026年秋季阶段」说明（家长会材料）。
4. `teacher` 登录 → 我的班级 → 最新一节课「去点评」：上传照片、打六维分、写建议。
5. `teacher` → 家长提问：回复黄思远爸爸的"作品不像样"，勾选历史作品与能力标签作为证据。
6. `parent5` 登录 → 提问与老师回复：看到老师的证据化回复；「续费建议」页确认商业与教学分离。

## 目录结构

```
├── Dockerfile              # 多阶段：前端构建 → 后端构建 → 非 root 运行时（含 HEALTHCHECK）
├── docker-compose.yml      # app（发布 ${CC_PUBLISH_PORT}:3000）+ db（仅内部网络）
├── .env.example
├── server/                 # Express + TS：schema/种子数据/REST API
│   └── src/{db,seed,auth,report,index}.ts + routes/
└── web/                    # Vue3 + TS + Pinia
    └── src/{views,components,stores,router.ts,api.ts,types.ts}
```

## 本地开发（可选）

```bash
cd server && npm install && npm run dev     # 需本地 PostgreSQL 或改 DATABASE_URL
cd web && npm install && npm run dev        # Vite 代理 /api、/uploads 到 :3000
```
